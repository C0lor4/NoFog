# NoFog

### Remove the fog in water, lava and powder snow


**Supporting Version:** Horizon 26.3（nightly-2026-11-18）。

**Default Shortcut:** G, 可在 **Options -> Controls -> Key Binds** 修改

**Configuration:** **Options -> Mods -> NoFog -> Config**。
